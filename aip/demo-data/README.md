# Optional fictional demonstration roster

`talent-officers.json` contains the original 20 fictional demo officers and their existing generated headshots, restored without modifying the image bytes. It is optional test data, not an Army personnel roster. Do not treat fictional names, credentials, contact information or photos as real people or real contact details.

Load these records into TalentOfficer only when setting up a demonstration or acceptance test. Every record includes the complete profileJson, with its existing photo in photo_processed as a MIME-tagged base64 data URL. They have no ownerUserId; ordinary users cannot claim or edit unowned records. Do not create a production roster by silently importing these examples.

The app itself has no fallback demo photo mapping: each search result, detail dialog, and printable card uses the image stored in that officer's own profile. New photos are saved as photo_original. Images are excluded from searchableText and AIP prompts. No photo generation or manipulation service is required.

In the Git repository, the JSON stores the text profile fields and reuses the existing generated_photos/officer_*.png files through aip/demo_data.py. Packaging embeds the same photo bytes in each profileJson, so the release ZIP is self-contained and needs no external photo URLs. The local preview seed is generated by aip/scripts/restore-preview-photos.py.
